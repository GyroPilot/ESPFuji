ESPFuji Installer

ESPFuji is temporarily withdrawn. Page updated 21 November 2026.

ESPFuji has been taken down while a bug is fixed. The ESPFuji installer is switched off until a fixed version is ready. Until then you can use this page to put Alex's stock ESProFile firmware back.

Check back for updates. A fix is being worked on and tested on real Lisas. This page will say when a fixed ESPFuji is ready to install, so please look here again before you install anything else.

This browser cannot talk to USB devices.
Open this page in Chrome or Microsoft Edge on a Windows, Mac, Linux or ChromeOS computer. Safari, Firefox and phones cannot do it. This page must be opened over https. Use the link from the ESPFuji repository.

Puts the ESProFile back to the firmware it came with (emulator 1.6). Takes about one to two minutes. Your disk image on the SD card is not touched.

Report a bug

Opens the ESPFuji Issues page (a free GitHub account is needed). Please say which firmware version, which Lisa, and what you saw. ESPFuji reports go here, never to Alex.

What we found

While ESPFuji's Wi-Fi is connecting, or retrying a network it cannot reach, the ESProFile can occasionally store a block written by the Lisa with one or a few bytes missing. The Lisa is not told, so the damage shows up later. On one Lisa 2/10 it made the startup disk unusable ("You have no environments on the startup disk").

We reproduced it on a test bench with ESPFuji 1.1.1 and 1.1.2. The same test with Alex's emulator code and no Wi-Fi showed no damage in about 63,000 writes. Earlier ESPFuji versions have not been tested yet.

What to do

  • Back up your SD card (copy the disk image to a computer).
  • For any disk you care about, go back to Alex's stock ESProFile firmware with the button above until a fixed ESPFuji is out.
  • If you keep using ESPFuji meanwhile, keep backups and avoid writing important work to that disk.

Going back to the stock firmware

With the stock firmware the ESProFile is a disk for the Lisa exactly as Alex made it. The Lisa programs that use the network through ESPFuji (LisaFuji, the Browser and the others) will not reach the network until ESPFuji is back. Your disk image stays as it is, and espfuji.ini can stay on the SD card: the stock firmware ignores it, and it will be there when you return to ESPFuji.

Use a good USB cable. This matters more than anything else on this page. The installer sends four megabytes over the cable, and a worn, very long or charge-only cable can drop data partway through. The install then stops, or the ESP32 is left half-written and will not start, and the Lisa cannot see the ESProFile. Use a short cable that you know carries data (one you have used to copy files, not just to charge), and plug it straight into the computer: no hubs, extension cables, keyboard or monitor ports. If anything goes wrong, change the cable first, then run the install again.

Turn the Lisa (or Mac XL) OFF first. The USB cable alone powers the ESP32 while it is being written. The Lisa must not be powering it at the same time.

  1. Turn the Lisa off.
  2. Plug the USB cable into the ESP32 board on the ESProFile and into the computer.
  3. Click Install Alex's stock firmware above.
  4. A list of ports appears. Pick the one that appeared when you plugged the cable in (often named CP210x, USB Serial or usbserial) and click Connect.
  5. Click Install. The installer then asks you to confirm and says "All data on the device will be erased": that means the ESP32's own firmware only. The SD card and your disk image are not touched. Click Install again and wait until it says the installation is complete (about two minutes). Do not unplug the cable while it is writing.
  6. Unplug the USB cable, put the SD card back if you took it out, and start the Lisa.

If something goes wrong

  • No port in the list: try another cable (some only charge), or install the USB driver for the board's chip: Silicon Labs CP210x. Then reload this page. (Recent Macs need no driver: the port shows as CP2102 USB to UART Bridge Controller (cu.usbserial-…).)
  • It fails partway (for example "Invalid head of packet") or sits on "Connecting": close the installer, unplug the USB cable, plug it back in and click Install again. A failed try does no harm: the ESP32 simply needs the install run again before it will start. Plug the cable straight into the computer, not into a hub, keyboard or monitor.
  • The list of ports closes before you can pick one, or the port is "in use": close every other tab that has this installer open (and any serial monitor), then click Install again.
  • Still stuck on "Connecting"? Put the ESP32 into update mode by hand: it has two small buttons beside its USB socket, BOOT and EN (or RST). While the installer shows "Connecting", hold BOOT, tap EN, then let go of BOOT.
  • The installer says there is no firmware for this chip: this page carries the stock firmware for the ESP32 on the ESProFile boards only. For anything else, build it from Alex's repository.
  • The Lisa shows error 85 afterwards (or the ESProFile's light stays off or red): the ESProFile is not answering the Lisa. Usually the install did not finish. Turn the Lisa off, use a better cable plugged straight into the computer, and run the install again until it says the installation is complete. Then check that the SD card is pushed fully in; an external ESProFile should be powered up before the Lisa.
