ESPFuji Installer

Put ESPFuji 1.1.1 on an ESProFile from this page. No Python, no command line.

This browser cannot talk to USB devices.
Open this page in Chrome or Microsoft Edge on a Windows, Mac, Linux or ChromeOS computer. Safari, Firefox and phones cannot do it. This page must be opened over https. Use the link from the ESPFuji repository.

Takes about one to two minutes. Your disk image and espfuji.ini on the SD card are not touched.

Before you start

  • A computer with Chrome or Edge.
  • A USB cable that carries data (some phone cables only charge).
  • The ESProFile's ESP32 board, either the external ESProFile or the internal one inside the Lisa.

For an ESP32 that already works in an ESProFile (updating from Alex's firmware or an older ESPFuji). A brand-new ESP32 first needs Alex's one-time flash-voltage step (espefuse set_flash_voltage 3.3V, in the ESProFile README), which a web page cannot do. Without it the board will not start on the ESProFile.

Turn the Lisa (or Mac XL) OFF first. The USB cable alone powers the ESP32 while it is being updated. The Lisa must not be powering it at the same time.

Steps

  1. Turn the Lisa off.
  2. Plug the USB cable into the ESP32 board on the ESProFile and into the computer.
  3. Click Install ESPFuji 1.1.1 above.
  4. A list of ports appears. Pick the one that appeared when you plugged the cable in (often named CP210x, USB Serial or usbserial) and click Connect.
  5. Click Install and wait until it says the installation is complete. Do not unplug the cable while it is writing.
  6. Unplug the USB cable, put the SD card back if you took it out, and start the Lisa. Your Lisa programs work as before; ESPFuji's HELLO now answers ESPFuji 1.1.1.

If something goes wrong

  • No port in the list: try another cable, or install the USB driver for the board's chip: Silicon Labs CP210x. Then reload this page.
  • It stops or fails while connecting: unplug, plug in again and retry. Some older ESP32 boards need the slower command-line method: use flash_espfuji_release.py from the release page.
  • Want a backup of the old firmware first? This page cannot make one. The command-line script can: flash_espfuji_release.py backup, and its restore puts Alex's original firmware back at any time.
  • The ESP32-S3 image is included but has not yet been tried on hardware.

ESPFuji is Tim O'Connor's fork of Alex Anderson-McLeod's ESProFile firmware. It is not the official ESProFile firmware. Alex has approved of it being published but does not support it: ESPFuji questions and bugs go to the ESPFuji Issues page, never to Alex. The ESProFile boards and the stock firmware are Alex's.
